## 6. OFFLINE & ON-DEVICE AI

ShadowTalk supports **optional offline AI** when models are installed.

| Tier | Model | Size | Who |
|------|-------|------|-----|
| A (default) | SmolLM2 135M | ~130 MB | All users — banner or silent install |
| B | Gemma 3n E2B/E4B | ~1.7–3.2 GB | Profile → Offline AI |
| C | Bundled SmolLM | ~130 MB | Desktop installer |
| D | Ollama + qwen2.5:7b | ~4.5+ GB | Desktop sovereign mode |

### How to get offline AI
1. Visit /chatbot — may prompt to install ~130MB model after first session
2. Profile → **Offline AI** → download Gemma for better quality
3. Desktop app (/downloads) → optional bundled Ollama for air-gapped use

### Offline limitations to explain honestly
- Smaller models are **less capable** than cloud Pro models
- First download requires internet
- Not all tools work offline (web search, cloud images need connectivity)
- Elite tier marketed for "full offline mode" but Tier A is available to free users with limits

### Personal model (learns from you)
- Every user gets **"My ShadowTalk"** personal model
- Learns from chat turns privately on-device
- Works cloud + offline
- Customize in Model Fine-Tuning / Personal LLM panel

## 12. TROUBLESHOOTING

### Chat not loading
1. Check https://www.shadowtalk-ai.com/status
2. Hard refresh (Ctrl+Shift+R)
3. Try incognito / different browser
4. Disable ad blockers
5. Sign out and back in at /auth

### Messages not sending / limit reached
- Check daily limits (Free: 50 msg/day)
- Guest users: sign in for higher limits
- Upgrade at /pricing

### Offline model won't download
- Need stable internet for first download (~130MB–3GB)
- Check storage space
- Try Profile → Offline AI → Retry
- Desktop: use /downloads for bundled installer

### Voice / Live mode not working
- Grant microphone permission
- Check plan limits (Free: 3 voice sessions/day)
- Say "open live mode" or tap mic icon

### Payment not activating (Pakistan)
- Use /founder-access and submit payment receipt
- Allow 24–48 hours for manual activation
- Email shadowtalk68@gmail.com with transaction ID

### Blank screen / errors
- Clear cache, reload
- Try /chatbot directly
- Report to support with browser console errors if persistent
